# Data release: every individual prediction, score and decision

Generated by `scripts/62_build_release.py` (topology inputs by `scripts/62a_release_proteins.py`). Do not edit by
hand: rebuild instead. `lysis_release.xlsx` has every table below except `scan_proteins.csv.gz`, one sheet each.

**How to trace a number.** Manuscript figure -> report in `reports/` -> the rows here (filter by set, version,
class) -> the per-genome prediction file `reports/<set>/<version>/<genome>.tsv` -> the commit that froze it
(`prediction_versions.csv`, `commit_log.csv`). `build_checks.json` records that the rows reproduce the reported
scores exactly.

**Read with care.** Scan rows measure agreement with GenBank annotation, not accuracy; the
benchmark rows (CPT, experimental, reviewed) are the independent ground truth. Related genomes are not independent:
resample `gene_content_cluster`, not genomes.

### genomes.csv

One row per genome per set (a genome can be in more than one set only if it is a benchmark genome).

Columns: `set`, `genome`, `organism`, `host_genus`, `lab_host`, `length_bp`, `n_annotated_cds`, `n_genes_called_denovo`, `n_nested_lipoprotein_orfs`, `ani95_cluster`, `gene_content_cluster`, `taxonomy`, `first_submitted_year`, `genbank_date`, `description`

- `set`: benchmark or scan (see the set list above)
- `host_genus`: first word of the organism name when it reads '<Genus> phage ...'
- `lab_host`: GenBank /lab_host or /host qualifier
- `n_genes_called_denovo`: genes the predictor called from DNA (Pyrodigal + nested lipoprotein ORFs)
- `ani95_cluster`: single-linkage group at >= 95% whole-genome ANI (scripts/58)
- `gene_content_cluster`: single-linkage group at shared gene-content Jaccard >= 0.10: the resampling unit for every interval
- `genbank_date`: date on the GenBank LOCUS line (last modification)
- `first_submitted_year`: year of the earliest 'Submitted' reference: the time split against PHROGs uses >= 2022

### prediction_versions.csv

One row per frozen set of DNA-only predictions (reports/<set>/<version>/<genome>.tsv).

Columns: `set`, `prediction_version`, `description`, `used_in_reports`, `frozen_in_commit`, `date`, `n_genomes`, `holin_model_sha256`, `endolysin_model`, `endolysin_model_sha256`, `spanin_model_sha256`, `spanin_caller_sha256`, `context_params_sha256`

- `used_in_reports`: True for the version the scan reports and figures use
- `frozen_in_commit`: commit that added the predictions, before any annotation was read
- `*_sha256`: SHA-256 of the model file in that commit (compare with reports/final/FROZEN.md)

### scan_calls.csv

One row per scan x prediction version x genome x class. Scored against the genome's own GenBank annotation with the rules of scripts/52c: AGREEMENT WITH ANNOTATION, not accuracy.

Columns: `set`, `prediction_version`, `genome`, `class`, `call_id`, `call_tier`, `call_start`, `call_stop`, `call_strand`, `call_length_aa`, `call_P`, `call_rank_by_P`, `call_annotated_as`, `call_annotated_id`, `call_verdict`, `genome_annotates_class`, `n_annotated_genes`, `annotated_genes`, `annotated_best_rank`, `annotated_in_top5`, `annotated_found_by_gene_finder`, `call_is_annotated_gene`, `call_is_annotated_gene_or_overlapping_partner`, `annotated_max_identity_to_training`, `annotated_novelty`, `top5_ids`, `top5_P`

- `call_*`: the predictor's one call for the class (empty when it made none)
- `call_tier`: confident / candidate / 'no call'
- `call_rank_by_P`: rank of the call by its raw class probability (the call is chosen after genomic-context re-ranking, so it need not be rank 1)
- `call_annotated_as`: product name of the annotated CDS the call matches ('(not in annotation)' if none)
- `call_verdict`: agrees / annotated hypothetical/unknown / annotated with another function / annotated as another lysis class / unannotated gene
- `annotated_genes`: annotated CDS of the class: id:product:start..stop strand
- `annotated_best_rank`: best rank among the annotated genes in the predictor's per-class ranking
- `call_is_annotated_gene_or_overlapping_partner`: spanin pair-level agreement (the call overlaps an annotated gene of the class)
- `annotated_max_identity_to_training`: max Smith-Waterman identity of the annotated gene(s) to that class's training positives
- `annotated_novelty`: near-copy (>=95%) / known family (30-95%) / new family (<30%)

### scan_proteins.csv.gz

Every protein of every scanned genome, from the version used in the reports.

Columns: `set`, `genome`, `id`, `start`, `stop`, `strand`, `length`, `P_holin`, `P_endolysin`, `P_spanin`, `rank_holin`, `rank_endolysin`, `rank_spanin`, `call`, `high_conf`, `lysis_call`, `cassette`, `annotated_id`, `annotated_product`

- `P_holin / P_endolysin / P_spanin`: class probabilities
- `rank_*`: rank within the genome by that probability
- `call / high_conf / lysis_call / cassette`: the predictor's own output columns (DEPLOY.md)
- `annotated_id / annotated_product`: the annotated CDS this gene matches (same strand and stop codon, else sequence)

### call_proteins.csv

Every called lysis protein (any tier), the second strong holin and the spanin partner, in every scan, with sequence and membrane topology. call_proteins.faa holds the distinct sequences, named by sequence_id.

Columns: `set`, `pred`, `genome`, `role`, `tier`, `id`, `start`, `stop`, `strand`, `length_aa`, `sequence_id`, `ours_helices`, `ours_helix_spans`, `ours_n_terminus`, `ours_sar_rule`, `deeptmhmm_type`, `deeptmhmm_helices`, `deeptmhmm_n_terminus`, `deeptmhmm_topology`, `signalp`, `signalp_probs`, `holin_class_deeptmhmm`, `holin_class_ours`, `holin_class_agree`, `endolysin_SAR_consensus`, `spanin_member_type`, `sequence`

- `role`: holin / holin2 (next protein with P_holin >= 0.9) / endolysin / spanin / spanin_partner
- `sequence_id`: 's' + first 15 hex of SHA-256 of the sequence: the key used by the topology runs
- `ours_*`: our ESM-2 transmembrane predictor (scripts/55): helix count, spans, N-terminus side (positive-inside rule), SAR rule
- `deeptmhmm_*`: DeepTMHMM (BioLib): type (TM / SP / SP+TM / GLOB / BETA), helix count, N-terminus side, per-residue topology string
- `signalp / signalp_probs`: SignalP 6.0 (organism other, fast): prediction and class probabilities (OTHER, SP, LIPO, TAT, TATLIPO, PILIN)
- `holin_class_*`: I/II/III = 3/2/1 helices; DeepTMHMM is primary (reports/tm_experimental.md)
- `endolysin_SAR_consensus`: SAR only where our rule and DeepTMHMM (signal-like N terminus) agree
- `spanin_member_type`: o-spanin (SignalP LIPO, no helix after residue 35) / u-spanin (LIPO + C-terminal-half helix) / i-spanin (helix starting in the first 40 residues) / other

### topology_reference.csv

Swiss-Prot phage lysis proteins through all three topology tools (the curated reference for call_proteins).

Columns: `id`, `length`, `roles`, `ours_helices`, `ours_nterm`, `deeptmhmm_type`, `deeptmhmm_helices`, `deeptmhmm_nterm`, `signalp`, `lipobox_rule`, `sequence`

### benchmark_genes.csv

One row per curated lysis gene in the CPT, experimental and reviewed benchmarks.

Columns: `benchmark`, `genome`, `class`, `gene_id`, `product`, `start`, `stop`, `strand`, `length_aa`, `proteins_in_genome`, `known_family_rank`, `known_family_score`, `unseen_family_rank`, `unseen_family_score`, `remote_removed_rank`, `remote_removed_score`, `phrogs_best`, `phrogs_annotation`, `phrogs_category`, `phrogs_bitscore`, `phrogs_evalue`, `phrogs_rank_for_class`, `pfam_lysis_domains`, `pfam_rank_for_class`, `sequence`

- `*_rank / *_score`: rank and score of the gene in its genome under leave-one-genome-out training with near-copies (known_family), >=30% families (unseen_family) or jackhmmer remote homologues (remote_removed) removed
- `phrogs_*`: best PHROGs v4 hit (E <= 1e-5) as Pharokka assigns it; phrogs_rank_for_class is its rank among proteins whose best PHROG is of this class
- `pfam_lysis_domains`: Pfam lysis-family hits: accession name (class, grade, i-Evalue)

### benchmark_genomes.csv

Per benchmark x class x method x genome with a curated gene: the method's top protein is the curated gene (call), a curated gene in its top 5, and whether it assigns the class to the curated gene at all (coverage). Aggregates are in reports/baselines/.

Columns: `benchmark`, `class`, `method`, `genome`, `call`, `top5`, `coverage`
